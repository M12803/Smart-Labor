## الوضع الحالي (تم فحصه)

- مجلد المشروع الحالي **فارغ**: يحتوي فقط قالب TanStack Start الافتراضي (`src/routes/index.tsx` بصفحة placeholder، `__root.tsx`، `styles.css`). لا يوجد أي كود للحاسبة ولا Supabase.
- الأرشيف المرفوع يحتوي **223 ملفاً** للتطبيق الكامل: محركات الحساب (`src/lib/calculator.ts`, `src/lib/saudi/engine.server.ts`)، منظومة الدفع والفواتير (`src/lib/billing/billing.functions.ts`, `src/routes/subscribe.tsx`, `payment-methods.tsx`, `ReceiptPreview.tsx`)، التقارير (`src/lib/pdf.ts`, `src/lib/saudi/report-*`)، لوحة إدارة كاملة (21 صفحة تحت `_authenticated/_admin/`)، و 35 ملف migration.
- لا يوجد `.git` داخل الأرشيف (تم التحقق).

لذلك الخطوة صفر إلزامية: **استعادة المشروع من الأرشيف**، وبعدها تُطبَّق المراحل على الكود الأصلي نفسه بأقل تعديل ممكن.

## الخطوة صفر — استعادة المشروع

1. فك الأرشيف في مجلد مؤقت ونسخ الملفات إلى المشروع مع استثناء `.git` و `.env` و `bun.lock`/`package-lock.json` المتضاربة و ملفات `.lovable/plan*`.
2. تفعيل Lovable Cloud (باك-إند جديد).
3. تشغيل جميع migrations الموجودة في `supabase/migrations` بالترتيب على القاعدة الجديدة (بدون بيانات المستخدمين القديمة).
4. تثبيت الحزم والتأكد من نجاح البناء وعمل الصفحات قبل أي تعديل وظيفي.

لن يتم أي refactor أو إعادة تسمية أو نقل كود في هذه الخطوة — نسخ كما هو.

## الدفعة 1 — التسجيل، الأسعار، التواصل، النصوص، الهوية

(المراحل 1، 2، 3، 4، 5، 7)

### التسجيل + قاعدة البيانات
- تعديل `src/routes/auth.tsx` فقط: إضافة قائمة منسدلة لرمز الدولة (+966 / +967) وتحقق Regex لكل دولة، مع الاحتفاظ ببنية النموذج الحالية.
- Migration واحدة تضيف على جدول المستخدمين/الملفات الشخصية: `phone_number` (NOT NULL + UNIQUE)، `country` (SA/YE مع CHECK)، `free_trial_used` (boolean default false) — مع GRANT وسياسات RLS بنفس نمط الجدول الحالي.

### التجربة المجانية مرتبطة بالحساب
- تعديل منطق البوابة الحالي (`src/components/AccessGate.tsx`, `src/lib/useAccess.ts`) ليستعلم من قاعدة البيانات قبل السماح بالتجربة: إن كان البريد أو رقم الهاتف قد استخدمها سابقاً → تحويل مباشر لصفحة الدفع.
- بعد انتهاء التجربة يُحدَّث `free_trial_used = true` عبر server function.
- اليمن (YE): التجربة غير متاحة — انتقال مباشر للدفع. السعودية (SA): متاحة مرة واحدة، بالنتيجة الإجمالية فقط بدون تفاصيل وبدون PDF.

### الأسعار حسب دولة الحساب
- تحديث **قيم** الأسعار فقط في مصدر الأسعار الحالي (billing/subscribe/إعدادات النظام):
  - SA / SAR: 5 للحسبة، 15 شهري، 100 سنوي — الدفع Visa عبر طبقة الدفع الحالية.
  - YE / YER: 700 للحسبة، 2,000 شهري، 14,000 سنوي.
- ربط العملة والأسعار ووسائل الدفع والفواتير و PDF ورسائل البريد/واتساب بـ `profile.country` بدلاً من اختيار الواجهة.
- **لا يُعاد بناء منظومة الدفع اليمنية** — تحديث قيم الأسعار فقط.

### التواصل والنصوص والهوية
- إضافة الرقم `966542152395` كرابط `https://wa.me/966542152395` في `AppHeader.tsx`، `ContactBar.tsx`/`FooterAttribution.tsx`، وصفحة التواصل.
- تحديث النصوص التسويقية الحالية (نظام العمل السعودي، قانون العمل اليمني، التقارير القانونية) دون تغيير التصميم.
- اعتماد الاسم «حاسبة العمال الذكية» / «SMART LABOR CALCULATOR» في العنوان، الشعار النصي، التنقل، الرئيسية، التذييل، صفحات الحساب، PDF/الفواتير، و SEO — بدون تغيير الألوان أو الخطوط أو الشعار المصور.

## الدفعة 2 — نظام الإحالات

- Migration: جداول الإحالات (رمز لكل مستخدم، استخدامات، إحالات ناجحة)، محفظة برصيد مفصول بالعملة (SAR/YER)، عمولات، وإعدادات قابلة للتعديل من لوحة التحكم (نسبة الخصم الافتراضية 10٪، قيمة الرصيد لكل إحالة، نسب العمولة، عتبات الاشتراكات المجانية 10/25/50) — مع RLS وGRANT.
- ربط احتساب المكافأة بنجاح الدفع فقط، عبر نقاط التحقق الموجودة في منظومة الدفع الحالية (بدون تعديل منطقها).
- صفحة مستخدم جديدة «برنامج الإحالات» تعرض الرمز والرابط ونوع المكافأة والاستخدامات والإحالات الناجحة وإجمالي الخصومات والمبيعات والرصيد/العمولات، مع زر تغيير نوع المكافأة.
- صفحة إدارة جديدة تحت `_admin` لتغيير نوع المكافأة، الخصم، العمولات، العتبات، تعطيل رمز، الإحصائيات، وتصدير Excel/PDF.
- نوع مكافأة واحد فقط لكل حساب في الوقت نفسه.

## الدفعة 3 — دعم العربية والإنجليزية

- إضافة طبقة i18n قابلة للتوسع (قواميس `ar` / `en` + مزوّد في `__root.tsx`) مع حفظ اللغة في حساب المستخدم (عمود `language`) والرجوع للتفضيل المحلي قبل تسجيل الدخول.
- مبدّل لغة في الرئيسية، تسجيل الدخول، إنشاء الحساب، شريط التنقل، والإعدادات.
- استبدال النصوص الثابتة في الواجهات بمفاتيح ترجمة، مع اتجاه RTL/LTR تلقائي على `<html dir>` والمحاذاة والخطوط.
- خيار «لغة التقرير» قبل الإنشاء، وتوليد PDF والفواتير ورسائل البريد وواتساب والإشعارات باللغة المختارة.
- SEO لكل لغة: Title / Description / Open Graph / Structured Data / hreflang.
- لا تُترجم ولا تُعدّل أي معادلة حسابية — العرض فقط.
